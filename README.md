# 💻 Tech Experience 2026

Projeto acadêmico desenvolvido para a disciplina de **Desenvolvimento Web**, com o objetivo de criar um sistema de inscrição para oficinas técnicas utilizando HTML, CSS, JavaScript e PHP.

## 🚀 Sobre o projeto

O Tech Experience 2026 é uma página de inscrição onde os participantes podem preencher seus dados, escolher seu nível de experiência, selecionar oficinas de interesse e enviar uma mensagem de motivação.

O sistema também conta com validações no navegador e no servidor, garantindo maior segurança e integridade dos dados.

## 🛠️ Tecnologias utilizadas

- **HTML5:** Estruturação da página e do formulário.
- **CSS3:** Estilização e responsividade.
- **JavaScript:** Interatividade, contador de caracteres e validações.
- **PHP:** Processamento do formulário e validação dos dados no servidor.

## ✨ Funcionalidades

- Formulário de inscrição.
- Validação dos campos obrigatórios.
- Seleção de oficinas de interesse.
- Contador de caracteres em tempo real.
- Processamento dos dados com PHP.
- Proteção contra ataques XSS.
- Bloqueio de requisições com método HTTP não permitido.

## ▶️ Como executar o projeto

1. Instale o PHP em seu computador.
2. Abra o terminal dentro da pasta `tech-experience`.
3. Execute o comando:

```bash
php -S localhost:8000
```

4. Abra o navegador e acesse:

```text
http://localhost:8000/index.html
```
